# Cuaderno AC · Arquitectura de computadores

Web estática de estudio en español, con 65 preguntas y respuestas en tres niveles, búsqueda, acordeones independientes, progreso local de repaso y una guía detallada de dos laboratorios.

[Abrir la web](https://fabiannavarroo.github.io/cuaderno-arquitectura/)

También funciona sin conexión: descarga el repositorio o `cuaderno-arquitectura.zip` y abre `index.html` con el navegador.

## Material

- `index.html`: web completa, sin dependencias externas.
- `resumen-laboratorios.md`: guía de hilos POSIX, Slurm, perf, Amdahl, pipeline, forwarding, saltos y reordenamiento.
- `registro-resultados.csv`: plantilla sin cifras experimentales para registrar medidas.
- `material/`: código, scripts, TXT original y enunciado del lab2.
- `LEEME.txt`: instrucciones de uso.

Los adjuntos originales no incluían medidas finales de ejecución. La guía distingue datos documentados, resultados deducidos, ejemplos teóricos y métricas pendientes. La respuesta original de la pregunta 65 se conserva junto a una corrección razonada. El valor de la pregunta 64 depende de diapositivas no adjuntas.

## Publicación

GitHub Pages publica la raíz de la rama `main`. `.nojekyll` permite servir directamente los archivos estáticos. Para actualizar la web, modifica los archivos y sube los cambios a esa rama.
